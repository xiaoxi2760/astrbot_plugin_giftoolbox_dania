# 娅娅表情处理工具箱

<p align="center"><img src="logo.png" alt="娅娅表情处理工具箱" width="200"></p>

基于 [iris1598/astrbot_plugin_gifcaijian](https://github.com/iris1598/astrbot_plugin_gifcaijian) 二次风格化改造的 AstrBot 插件。

原项目提供视频转动图、精灵图合成、速度调整、网格裁剪、逐帧分解、表情包做旧等多功能 GIF 处理；本fork在此基础上集成《鸣潮》角色**达妮娅（娅娅 / Denia）**风格的提示文案与别名指令。

> 文案基调参考自萌娘百科/百度百科人物资料：星炬学院·虚质科学部学生，温柔慵懒、爱说俏皮话、爱打盹；异能力「泡影视阈」；常态温柔、大招切黑化形态。所有面向用户的提示与结果信息均呈现该风格；高倍速加速、倒放、做旧等「反转/失真」类操作还会触发一句黑化彩蛋。

### 0.5 表情帮助指令

发送 `表情帮助`（或 `表情包帮助` / `yy表情帮助`），娅娅会把表情包相关指令（表情包做旧、表情合成、网格裁剪）的用法一次性列给你～

### 1. 视频转动图

将视频文件或视频链接转换为动图格式（默认为GIF，可在配置中修改为APNG或WebP）。支持精细的参数控制，并能对生成的过大文件进行智能压缩。

- **指令:** `视频转gif [参数]`
- **使用方法:** 回复一个视频消息，或在指令后附上视频链接，并可选择性添加参数。
- **参数:**
    - **时间区间:** `1s-5.5s` 截取视频第1秒到第5.5秒；或 `开始 2s 时长 3` 从第2秒取3秒。
    - **抽帧/帧率:** `fps 10` 设置输出帧率为10；`1/3` 每3帧取1帧。
    - **缩放:** `0.5` 缩放为原尺寸50%。

### 2. GIF变速

- **指令:** `gif变速 [参数]`（`Nx` 倍速 或 `Nfps` 帧率），旧指令 `加速/减速 [倍数]` 仍可用
- **示例:** `gif变速 2x`、`gif变速 30fps`、`gif变速 60fps`（自动抽帧）

### 3. 网格裁剪

- **指令:** `裁剪 [参数]`
- **示例:** `裁剪 2x5 边距上20`

### 4. GIF分解

- **指令:** `gif分解`

### 5. GIF倒放

- **指令:** `gif倒放`（或 `倒放`）

### 6. 表情包做旧

模拟早期互联网图片传播效果：绿通道偏移 + JPEG失真 + 模糊 + 饱和度/对比度调整；动图逐帧处理再合成。

- **指令:** `表情包做旧 [次数]`
- 建议：1~5 轻度，5~10 中度，10~20 重度，>20 极限（赛博遗产级别）

### 7. 表情合成

把多张表情按顺序接成一条动图。

- **指令:** `表情合成 [速度/时长]`（如 `0.5` 静态图每帧0.5秒）
- **怎么给图:** 直接和图一起发、回复一条含图的消息、或者合并转发都行，自动居中填充统一画布，按输入顺序连接。
- **动图拼接:** 输入里有 GIF/动图时，会把它们的每一帧都接进去，按发出的顺序连成一条，**沿用各段原本的速度**；静态图占一帧、用上面的时长参数。
- 总帧数太多（超过 500 帧）时会自动抽掉一些，**总时长不变**。输出格式选 APNG / WEBP 时，各段速度会取平均值。

## 安装

将插件目录 `astrbot_plugin_giftoolbox_dania` 放入 AstrBot 的 `data/plugins/`，在管理面板「插件管理」中启用即可。

## 插件配置

```jsonc
{
    "output_format": "GIF",      // 动图输出格式: "GIF", "APNG", "WEBP"
    "default_scale": 0.3,        // 视频转动图默认缩放比例
    "default_fps": 10,           // 视频转动图默认帧率
    "max_gif_duration": 10.0,   // 允许截取视频的最大时长（秒）
    "result_split_mb": 1.0,      // 结果图超过该体积(MB)时拆分发送（避免 QQ 把动图转静态）
    "max_video_size_mb": 50.0,   // 允许下载处理的视频最大体积（MB）
    "gif_max_colors": 256         // 生成GIF时最大颜色数 (2-256)
}
```

## 依赖

- `Pillow`、`aiohttp`：AstrBot 运行环境通常已内置
- `imageio`、`imageio-ffmpeg`：**仅「视频转gif」需要**，缺失时该功能不可用（日志会有提示），其余功能不受影响
